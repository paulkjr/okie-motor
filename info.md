# Okie Motor

A search-and-control dashboard card for Home Assistant: lock page, status island, one search bar that finds anything
(and can ask your Assist agent), a bento start screen, detail views with video backgrounds, calendar, to-dos, energy,
news, schedules and a full settings app. One file, no dependencies.

Add the resource, then:

```yaml
type: custom:okie-motor-card
```

Use it as the only card of a **panel** view. Full guide: the repository README.
