# Features

| Area | Built |
|---|---|
| **Frame** | A 1200 px column scaled with CSS zoom, status island, search row, start screen, a dock on the left (a bottom bar on a phone), a height ladder (full, compact, drop the small tiles, stacked) and phone / tablet / desktop layouts. Lock page with clock, weather and power, a greeting or quote; swipe up, scroll or press a key to open. The top of the column is the same on every screen. |
| **Start screen** | Two columns. Left: favorites and suggestions (grid or list, three tabs: Favorites, Rooms, Suggestions) and the **Light modes** card. Right: one swipeable **Widgets** card (weather with hourly strip, to-dos, news with thumbnails, calendar, tips, cameras, Kindle, AWTRIX, and a home map when a separate `floorplan-card` custom card is installed) that can also be split into separate cards, a cameras card and a pet-feeder card with six looks (a compact row, and the five designs of the iOS feeder widget: pick one with the pencil while you arrange). |
| **Arrange by touch** | Hold a card to arrange: drag between and within the columns, Row / Tall / Large per card, a height handle per column with snap points (same height as the other column, whole cards), remove, Reset and Done in a bar at the bottom, tap away to finish. Rooms arrange the same way. |
| **Search** | One glass pill that grows into a panel: typewriter line, fuzzy typo-tolerant search, intent parser ("living room light" becomes area plus type), chip input with ghost completion, sub-category chips with live "on" counts, a filter popup (Tiles / List, Categories / Rooms / Recent), Devices / Sensors / Actions / Apps, 4 / 5 / 6 columns. |
| **Assistant** | A sparkle button turns the panel into a chat with your Home Assistant Assist agent. The devices an answer touched appear as tiles. A request typed into the search offers "Ask the assistant". **Voice**: the microphone listens, shows what it hears, and sends by itself when you stop talking; on the lock page it listens in place, turns red and pulses, and says the answer. |
| **Predictions** | Exponential-decay usage learning (slow / normal / fast), cold-start bootstrap, negative learning for ignored suggestions, reset any time. Excluded patterns with wildcards, live preview, templates, JSON import / export. |
| **Quick control** | The icon is the switch: tap safe devices, press and hold risky ones (unlocking, opening). Amber hold ring, haptic, per-device-type Off / Tap / Hold. |
| **Detail view** | Controls, Context, History, Schedule, Settings. Spring-animated **circular dials** (touch, mouse, keyboard) for lights, climate, fans, humidifiers; controls for covers, locks, media players, vacuums, cameras, alarms, scenes / scripts / automations, sensors, weather. **Video backgrounds** with a fall-back chain (`light_on.mp4`, `binary_sensor_motion.mp4`, `default_1..10.mp4`, then an icon). |
| **Thermostat** | The dial with a colour scale you set, modes, presets, fan, a weekly **schedule** with profiles (Comfort, Sleep, Eco, Away) when the Scheduler component is installed. |
| **Music** | A Spotify library browser (open it from the grid button), play on this tablet, synced lyrics. Players in three sizes: a row, a tall card, and a large cover card (cover, title, artist, a progress line you can tap, previous / play / next). Spotify gets its logo. |
| **Light modes** | A card of one-tap modes (a script, a scene, some lights or a whole room), side by side, stacked or icons only, with an editor and schedules. |
| **History** | 24 h / 7 d / 30 d: line chart with readout, min / avg / max, state timeline, time in each state, time-of-day bars, change count. |
| **Schedule** | With the [Scheduler component](https://github.com/nielsfaber/scheduler-component): list, pause, delete (6 s undo), new schedule with iOS-style wheel pickers and day chips. |
| **Apps** | **Calendar** (day / week / month / year; an endless date strip you scroll with a finger, ticking as it goes; create, edit, delete with undo, recurrence presets), **To-do** (live, overdue stacking, dictation), **Energy** (reads HA's Energy dashboard), **Schedules**, **News**, **Server links** (your own links to Home Assistant pages and other services), **Assistant**, **Tips**, **What's new**, **Settings**. |
| **Rooms** | Every area with devices is a room; each room opens like an app with a card per device, and arranges like the start screen. |
| **Settings** | Four tabs (General, Appearance, Filter, About), sections with an info button, sub-pages, a search field that jumps to the row, a **Changed** badge. Settings are kept in Home Assistant for your user and synced to every screen; export / import as a file. |
| **Notifications** | Island orb with a severity badge that opens into the list (severity, source tabs, snooze, dismiss), a notification centre (HA persistent notifications and derived smoke / gas / water / tamper / low-battery alerts), the house chronicle, toasts, a 6 s undo pill, quiet hours, a version watcher. |
| **Wall tablet** | Screensaver clock page, deep rest (dim, shrink, burn-in shift every 3 minutes, darker in quiet hours), wake sources (motion, doorbell, critical alert), shorter idle when nobody is home, a display handoff (a switch plus scripts), a photo frame from a media folder. |
| **Design** | Real `backdrop-filter` glass, four card shapes, one glass window for every popup (focus trap, Escape, reduced motion), a spring reveal, a fade-in scrollbar, a view-wide wallpaper. Cards at a scrolling edge fade out instead of being cut. |
| **Reliability** | Failed service calls toast and leave state alone; a view or control that throws shows a retry box instead of blanking the card; no optimistic state to desync. |
| **Okie Home (iOS)** | Full-screen app, native sign-in, haptics, speech recognition, pull-down to refresh, stays on the screen you were on, native widgets (Thermostat, Weather, Calendar, Lights, Feeder). |
| **Languages** | English and German; a test fails the build if the two ever differ. |

## Not built

Music Assistant library panel, the plugin store, a 3D-printer integration, the Liquid Glass refraction effect (the glass has blur, tint and the five background filters), hundreds of hand-drawn animated device icons (this has about 30 coloured drawings and a few small loops), calendar groups / event rules UI (the rules are implemented and tested), dictation through HA Assist (browser and iOS recognition only), languages beyond English and German.
